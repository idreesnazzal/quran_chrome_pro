## 4. مشاكل معروفة متبقية / محدوديات معلنة (بصراحة)

1. **مربعات التظليل تقديرية** (توزيع تناسبي حسب طول الكلمة فوق مستطيلات OCR للأسطر) — قد تنزاح في الأسطر المزدحمة. الحل الحقيقي: بيانات كلمات بمستطيلات حقيقية (QPC/quran.com) — موثق في SPEC كبند إلزامي للمطوَّر الجديد.
2. **نموذج Whisper المدقق غير مُنزّل بعد** — السيرفر يعمل `--no-model` (استضافة + إذن مايك). التحميل الأول ~500MB ثم يعمل محليًا. لم يُختبر صوتيًا من طرفنا (لا مايك هنا) — الاختبار الحي عليك.
3. **دقة الثقة المعروضة أثناء التتبع (92%) تجميلية** — حقيقية فقط عند القفزات العامة. لا تؤثر على السلوك.
4. **المساران الصوتيان يعملان معًا** عند تفعيل السيرفر (المتصفح + Whisper) — قرار مقصود (المتابع مصمم للضجيج المختلط)، لكن يستحق مراقبة حية.
5. **تقسيم الكلمات = تقسيم النص البياني** (يا أيها كلمتان) بينما العرض العثماني يلحمها — موثق كبند إلزامي (جدول ربط) في برومبت التوظيف.
6. **عداد `lowStreak` ودالة `detectActiveWordInAyah` و`RECITE_vocab`** — بقايا ميتة غير ضارة، أُبقيت عمدًا (عقد/مستقبل). تنظيفها تجميلي.
7. **OneDrive يزامن 604 صور (~60MB)** — بطء مزامنة محتمل. وGit بلا أي commit وبلا `.gitignore` (الـ60MB ستنفخ المستودع إن أُضيفت).
8. **ملف النسخة الاحتياطية + مجلد css الفارغ + سكراتش القديم** — قمامة منظمة بانتظار قرارك (القسم 8).

## 6. صعوبات واجهناها (ودروسها)

- **انقطاع الجلسات → تعديلات ناقصة:** دالة وُلدت داخل دالة (خطأ #13) — الدرس: تحقق آلي بعد كل تعديل، لا ثقة.
- **نماذج ذهنية خاطئة عن النص** (تخمين كلمات 18:43، حساب lev بالعقل) — الدرس: التتبع المطبوع يتفوق على التخمين دائمًا (D1 حُسم بـtrace لا بجدال).
- **جحيم علامات PowerShell** (اقتباسات `python -c`، لا `head`، الـjobs لا تعيش بين الاستدعاءات، ترميز cp1252 العربي) — الحل: ملفات سكربت + قراءة من ملفات + `Start-Process` للسيرفرات.
- **علامة truncation داخل ملف حقيقي** (`...[truncated ...]` تسربت لكود المحرك) — اكتُشفت بفحص syntax، والآن كل كتابة تُتحقق.
- **اختبارات على corpus لعبة (6 آيات) تُخفي/تُظهر bugs وهمية** (حارس ≤3 ابتلع القفزات) — الحل: corpus حشو + corpus حقيقي 6,236 جنبًا لجنب.
- **اختبار المستخدم لتبويب قديم بكود ميت** — الحل: علامة إصدار (`ReciteByMic.version`) + `no-store` على JS.
- **تقارير بالصور فقط بلا نص** — تعلمنا قراءة الثلاثية (المتلو/المعروض/نص الشريط) واستنساخها كاختبار قبل أي إصلاح.
